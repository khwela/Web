# Web Development  Project

## Description
This project is a web application built using HTML and CSS. It serves as a platform for showcasing your skills and professionalism.
The project is fuctional we are not really prode of it , we   will try our best to do better.

## Features
-This project consist of 6 pages, footer and a header with navigation links to the sections.
- The first section have navigations links , and professionalisms
- The second section have the bio with the details of the user , downloadable cv and hire me which directs to contact section. And social media icons , which you follow.
- The third section have our services , what the user can offer.
- The forth section have label of the skills .
- The fifth section have the number of projects the user have completed, working hours, online support and customer feedback.
- The sixth section have the success of the users  work.
